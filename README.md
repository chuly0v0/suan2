# 蒜了 2.0

一本简约手绘风的家常菜谱。静态 HTML / CSS / JavaScript，可直接部署到 GitHub Pages。包含手机厨房首页、便利贴红叉重选与绿钩加菜、自绘图标、联动筛选、砂锅选菜、菜品管理和 CSV / Excel 导入导出。

## 上传与发布

把本目录内全部文件和 assets 文件夹上传到 GitHub 仓库根目录，保留文件层级；不要再套一层“蒜了2.0”。根目录必须有 index.html、styles.css、icons.js、storage.js、app.js、offline.js、sw.js 和 .nojekyll。

Settings → Pages：Source 选 Deploy from a branch，Branch 选 main，Folder 选 / (root)。无需安装依赖。上传包中的缓存版本已生成，可以直接上传。

## 缓存与离线

第一次在线打开后，后台准备离线所需资源。准备完成后再次打开，页面、图片、字体等优先读取本机缓存；支持离线浏览和已缓存的 Excel 导入。其余字体按菜谱所需汉字加载并缓存。浏览器仍可能进行小体积的版本检查。

离线缓存需要 HTTPS（本机 localhost 也可以），直接双击 index.html 的 file:// 预览无法启用。首次下载尚未完成时，不能保证离线使用。

新版本下载完成后会提示“有新版可用”，点击“更新页面”再切换，避免打断正在填写的菜品。若开了多个蒜了标签页，请关闭其他标签页后再点更新。

## 数据保留

菜谱与砂锅沿用 garlic_recipes、garlic_cart 两个 localStorage 键。正常刷新、关闭浏览器和更新网页资源不会主动清空它们。导入或管理菜品时会请求浏览器持久存储，授权由浏览器决定；保存失败会明确提示并保留原数据。

数据保存在当前浏览器，不会上传服务器或自动同步到其他设备。清除站点数据、无痕窗口结束或浏览器存储清理仍可能导致丢失，请定期用“下载模板”导出当前菜谱备份。

同一账号 github.io 下的不同项目属于同一来源，会共用这两个旧有数据键。“更新数据”只改变当前浏览器中的菜谱，不修改 GitHub 上的默认数据。

## 以后修改网页

修改图片、代码或字体后，运行本地“发布工具/更新缓存版本.cmd”，再上传变更文件和新 sw.js。导入个人菜谱不需要此步骤。

## 体积优化

默认两种字重的首批字体合计约143KB；完整汉字字库拆分按需加载。企鹅动画使用无损动画 WebP，保持原帧与时长；菜单底图和静态企鹅已缩小。Excel 脚本仅在导入或导出 Excel 时加载执行，复用已有依赖。开发脚本、原始绘画、字体原件和检查结果不放入本发布目录。

## 导出当前菜谱

右侧“编辑菜品”上方的“导出菜谱”会下载带日期的 .xlsx 文件，包含当前浏览器中的完整菜谱，不受类别或筛选条件影响。表头是菜名、食材、类别、种类、烹饪方式、难易程度、口味、配料，可以通过“更新数据”重新导入。“下载模板”仍提供原有 CSV 下载。首次在线缓存准备完成后也可以离线导出 Excel。
